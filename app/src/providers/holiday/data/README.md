# China Holiday Data

## 数据来源

- 2025: 国务院办公厅关于2025年部分节假日安排的通知（国办发明电〔2024〕12号）
- 2026: 国务院办公厅关于2026年部分节假日安排的通知（国办发明电〔2025〕7号）
- 2027: 待官方发布

## 最后校验时间

2026-06-11

## 维护原则

1. **仅允许录入国务院办公厅已发布的数据**
2. **禁止录入预测数据**
3. **禁止录入未经验证的数据**
4. **未来年度在官方通知发布前保持空数据集**

## 数据状态

| 年份 | 状态 | 说明 |
|------|------|------|
| 2025 | `verified` | 已验证（国办发明电〔2024〕12号） |
| 2026 | `verified` | 已验证（国办发明电〔2025〕7号） |
| 2027 | `pending` | 等待国务院办公厅发布 |

## 如何更新数据

当国务院办公厅发布新的节假日安排通知时：

1. 获取官方通知的完整文本
2. 提取节日名称、放假日期、调休安排
3. 更新对应年份的 JSON 文件
4. 将 `_meta.status` 改为 `verified`
5. 填写 `_meta.source` 和 `_meta.verifiedAt`
6. 为每条记录添加 `source` 字段
7. 更新本文件的"数据来源"和"最后校验时间"

## 数据格式

```json
{
  "_meta": {
    "year": 2026,
    "status": "verified",
    "source": "国务院办公厅关于2026年部分节假日安排的通知",
    "verifiedAt": "2026-06-11"
  },
  "holidays": [
    {
      "date": "2026-01-01",
      "name": "元旦",
      "type": "festival",
      "source": "国务院办公厅关于2026年部分节假日安排的通知"
    }
  ]
}
```
