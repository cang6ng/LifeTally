# 产品基线

## 定位

LifeTally 是本地优先的个人生活管理网页。它把日期安排、临时想法和使用环境放在三个稳定页面中，不承担账号同步、团队协作或专业知识库职责。

## 三个主页面

### 日历

- 默认入口。
- 按月浏览和选择日期。
- 管理纪念日、事件、Deadline、To Do 和 Daily To Do。
- 右侧 Overview 按类型显示对象并支持折叠、新建和完成状态切换。

### 便利贴

- Inbox 保存所有活跃便利贴。
- 已转换只显示最近五次类型转换记录。
- 回收站显示所有被软删除的对象，只允许恢复或彻底删除。
- 便利贴可转为任意计划对象，计划对象只能直接转回便利贴；转换保持同一个对象 id。

### 壁纸库

- 默认壁纸随应用内置。
- 用户图片以本地 Blob 保存，不接收外部壁纸 URL。
- 支持上传 PNG/JPEG/WebP、切换、重命名和删除。
- 壁纸页不显示右侧 Overview。

## 对象模型

稳定对象类型为：

- `anniversary`：纪念日
- `event`：事件
- `deadline`：Deadline
- `todo`：To Do
- `dailyTodo`：Daily To Do
- `note`：便利贴（仅为内部类型名）

所有对象具有 id、标题、内容、创建/更新时间和 `active | archived | trashed` 状态。用户可见文案统一使用“日历”和“便利贴”。

## 明确不包含

- 当前版本没有搜索页。
- 不读取浏览器书签、历史或其他标签页。
- 不提供账号、服务器、云同步、遥测或广告。
- 便利贴不扩展为文件夹、资料库或 Markdown 长文系统。
- 当前版本不是浏览器扩展，也不承诺 GitHub Pages 在线服务。
