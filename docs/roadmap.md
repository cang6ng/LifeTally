# 路线图

## v0.1：开源稳定基线

- 三个稳定页面和统一 App Shell。
- 独立 IndexedDB 与 namespaced localStorage。
- 备份 V1、数据诊断、回收站和本地壁纸。
- MIT 许可、社区文档、CI 和干净公开历史。

## v0.2：测试与可靠性

- 使用 Vitest 和 fake-indexeddb 测试真实数据库迁移。
- 使用 Playwright 覆盖刷新、备份、回收站和壁纸。
- 增加数据库初始化失败页面和应用 Error Boundary。
- 为大型壁纸增加配额和错误提示测试。

## v0.3：维护性与性能

- 按页面动态加载，降低首屏主包体积。
- 引入 ESLint、Prettier 和稳定的提交前检查。
- 减少 `any`，补充对象类型守卫。
- 完成键盘导航、焦点、对比度和屏幕阅读器验收。

## 可选探索

- 独立搜索 feature。
- 浏览器新标签页扩展包装。
- 其他本地优先组件。

可选功能必须能独立删除，不得成为 core schema、备份或稳定页面的反向依赖。账号、云同步和遥测当前不在路线图内。
